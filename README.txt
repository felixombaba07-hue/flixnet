FLIX NET LATEST UPGRADED SITE
============================
Netlify-ready FLIX NET portal with:
- Customer registration/login
- Package display and admin package controls
- Responsive black/orange design
- WhatsApp support
- Netlify Functions scaffold for Paystack initialization/verification
- Environment-variable based secrets

NETLIFY ENVIRONMENT VARIABLES
PAYSTACK_SECRET_KEY
PAYSTACK_PUBLIC_KEY
HOTSPOT_TYPE
HOTSPOT_HOST
HOTSPOT_USERNAME
HOTSPOT_PASSWORD
ADMIN_PHONE
WHATSAPP_NUMBER

IMPORTANT
The included Paystack functions keep the secret key server-side. Automatic hotspot activation requires the actual router/hotspot API details and a persistent backend/database. The hotspot variables are prepared for that integration; do not put secrets in frontend files.
